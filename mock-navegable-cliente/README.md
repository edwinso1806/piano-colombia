# Piano Colombia — Mock Navegable de Demostración

Esta carpeta contiene la copia de respaldo completa y aislada del **Frontend & Mock Navegable** (28 rutas funcionales) desarrollada con Next.js App Router y Tailwind CSS.

## 🚀 Cómo Iniciar el Mock

1. **En Windows (Recomendado):**  
   Haz doble clic en el archivo `iniciar_demo.bat`.

2. **En Terminal:**  
   ```bash
   npm install
   npm run dev
   ```

Abre tu navegador en: **http://localhost:3000**
